## 2. FIX THE SCROLL SEQUENCE

The current title animation begins too late. For example, “THE CAFÉ” is still incomplete when the Padel scene starts.

Each scene must follow this exact sequence:

1. The gold line reaches the scene.
2. The main and secondary images enter and settle.
3. The title starts writing immediately.
4. The complete title becomes clearly visible.
5. The description appears.
6. Hold the completed scene for approximately 25–35vh of scrolling.
7. Only then may the next scene begin.

The next scene’s images must never enter before the current title is 100% complete.

The current timing resembles:

* `revealStart = yFrac - 0.01`
* `revealEnd = yFrac + 0.13`

This writing window is too late and too long. Replace it with a shorter earlier window, approximately:

* `titleStart = yFrac - 0.055`
* `titleEnd = yFrac + 0.035`
* `subtitleStart = titleEnd - 0.01`
* `nextSceneEntryStart >= titleEnd + 0.025`

Adjust responsively if necessary, but preserve the sequence above. Scrolling backward must reverse everything smoothly.
